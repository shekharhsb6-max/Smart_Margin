XIRR / CAGR

Time-weighted annualized return across all margin cash flows (buy = outflow, sell or today's mark-to-market = inflow, eligible dividends = inflow on record date). More meaningful than a flat % since your positions open and close on different dates.

Portfolio Position On A Date

Trailing Stop-Loss & Target

Stop-Loss only ever moves up (locks in gains); Target keeps re-extending upward once price clears it, so a strong trend isn't capped. Both are computed off each position's Highest Price Since Buy. Applies only to positions with "trailing enabled" (default on, per-position toggle in Add/Edit).

Runs updateTrailingLevels() on a timer, even with the sheet closed, so trailing SL/Target keep ratcheting through the day. For GOOGLEFINANCE to have fresh prices between runs, set this spreadsheet's File > Settings > Recalculation to "On change and every minute". This trigger is installed inside Apps Script itself, so it runs on Google's servers regardless of whether this app is open.
